# 09 — Build roadmap and acceptance

## Phase 0 — Evidence and decisions

Confirm brand architecture, product naming, target geography, current capabilities, integrations, deployment offerings, pricing model, proof assets, and legal/security review owners.

## Phase 1 — Strategy and content

Approve messaging, sitemap, homepage wireframe, trust claims, CTA flow, consultation questions, and content inventory.

## Phase 2 — Design system and prototype

Create type, colour, spacing, navigation, CTA, workflow-trail, process-timeline, comparison, trust, and form components. Prototype desktop and mobile.

## Phase 3 — Launch build

Build homepage, How it works, What it supports, Privacy and deployment, About, Consultation, legal pages, analytics, accessibility, and content management workflow. Add Pricing, Compare, or Resources only if their evidence and ownership are ready; otherwise stage them behind the launch navigation.

## Phase 4 — Proof and optimisation

Add case study, integration page, trust centre, ROI tool, pricing, or localisation only after evidence and user feedback justify each one.

## Acceptance checklist

### Message

- Nella is clear within one screen;
- the site does not depend on the Anna persona;
- no unsupported “AI lawyer” or replacement language;
- primary CTA is consistent.

### UX

- all navigation and forms work;
- mobile layout is intentionally adapted;
- keyboard focus and screen-reader labels are complete;
- motion respects reduced-motion preferences;
- no important content is hover-only.

### Trust

- every security/privacy claim has an owner and evidence source;
- fictional demos are labelled;
- current regulatory references have review dates;
- legal, privacy, and cookie content is reviewed.

### Performance and operations

- responsive images and restrained animation;
- fast first load and good Core Web Vitals;
- consultation events are measurable without excessive tracking;
- error, success, spam, and abandonment states are designed;
- content can be updated without a code release where appropriate.
