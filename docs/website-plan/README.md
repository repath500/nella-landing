# Nella website plan

This folder is the working blueprint for the best version of the Nella website.

## Core decision

The public website is for **Nella**, the company and trusted implementation partner. It should sell a private, managed assistant system for law firms and professional teams. It should not be framed as a generic AI tool, an agent platform, or a website built around a single assistant persona.

The product/persona name can appear in demos or product material later, but Nella owns the relationship, delivery, privacy model, deployment choices, and ongoing improvement.

## Non-negotiables

- Lead with useful work and trust, not AI terminology.
- Show how Nella works inside existing workflows.
- Make human accountability and approval visible.
- Treat deployment, model choice, privacy, and retention as product features.
- Use one primary conversion: **Book a private consultation**.
- Do not publish technical, regulatory, client, performance, or pricing claims until they are evidenced.
